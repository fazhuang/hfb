# Image — 图像知识

古籍图像处理规范。

## 图像类型

- 古籍扫描页（TIFF/JPEG 原始扫描）
- 插图（书内插图）
- 拓片/碑刻
- 地图
- 文物照片

## 处理规范

- 格式：TIFF（存档）/ JPEG（Web）/ PNG（插图）
- 分辨率：≥ 300 DPI（存档）
- 色彩模式：灰度（古籍正文）/ RGB（插图）
- 命名：`{book_id}_{page_number}.{ext}`
