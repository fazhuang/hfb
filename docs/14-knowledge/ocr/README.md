# OCR — 文字识别规范

古籍 OCR 处理规范。

## V1 阶段

平台 V1 接受已识别的文本输入，不内置 OCR 引擎。

## 输入格式

- 已分段、已校对后的纯文本
- JSON / CSV 格式导入
- 包含元数据：书籍 ID、版本、章节、段落序号

## 质量标准

- 识别准确率：≥ 98%（导入前人工校对）
- 异体字处理：标注异体字，附正字

## 未来 V2

- 集成 OCR 引擎（Tesseract / PaddleOCR）
- 支持古籍刻本、抄本识别
- 异体字自动识别和映射
