# Book — 古籍知识

古籍文献的结构化知识。

## 文献分类

- 医经（《黄帝内经》《难经》）
- 本草（《神农本草经》《本草纲目》）
- 方书（《伤寒杂病论》《千金要方》）
- 针灸（《针灸甲乙经》）
- 哲学（《道德经》《庄子》）
- 历史（《史记》《汉书》）

## 版本类型

- `base` — 底本（原始版本）
- `collated` — 校本（校勘后的版本）
- `annotated` — 注本（带注释的版本）
- `translation` — 译本（现代汉语翻译）
