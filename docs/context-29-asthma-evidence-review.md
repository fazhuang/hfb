### 卷十二：小儿杂病第十一（儿科专篇 — 关键证据）

**原典全文**：

```
小兒雜病第十一

嬰兒病，其頭毛皆逆上者，死。

嬰兒耳間青脉起者，瘈，腹痛，大便青辦，飱泄，脉大，
手足寒，難已；飱泄，脉小，手足温者，易已。

驚癎脉五，鍼手足太陰各五，刺經太陽者五，刺手足少陰
經絡傍者一，足陽明一，上踝五寸，刺三鍼。

小兒驚癎，本神及前頂、𩕄會、天柱主之。如反視，臨泣主之。
小兒驚癎加瘈瘲，脊急强，目轉上插，縮筋主之。
小兒驚癎，瘈瘲脊强互相引，長强主之。
小兒食晦，頭痛，譩譆主之。
小兒癎發，目上插，攅竹主之。
小兒臍風，目上插，刺絲竹空主之。
小兒癎痓，嘔吐瀉注，驚恐失精，瞻視不明，眵䁾，瘈脉及長强主之。

小兒驚癎，不得息，顱𩕄主之。          ← ★ 核心证据 ★

小兒驚癎如有見者，列缺主之，并取陽明絡。
小兒口中腥臭，胷脇榰滿，勞宫主之。
小兒欬而泄，不欲食者，商丘主之。
小兒癎瘈，手足擾，目昬，口噤，溺黄，商丘主之。
小兒癎瘈，遺精，溺虚则病諸癎癲，實則閉癃，小腹中熱，善寐，大敦主之。
小兒臍風，口不開，善驚，然谷主之。
小兒腹滿不能食飲，懸鍾主之。
小兒馬癎，僕參及金門主之。

風從頭至足，癎瘈，口閉不能開，每大便腹暴滿，按之不下，
𡁲、悲、喘，崑崙主之。                ← ★ 含"喘"的最后一条 ★
```

## 四、最终结论

### 结论：PASS（有原典证据，但严格限缩解释）

| 判断 | 详情 |
|------|------|
| **有直接原典证据？** | 是 — 卷十二"小兒驚癎，不得息，顱𩕄主之"明确为儿科呼吸相关取穴条文 |
| **可诊断为现代哮喘？** | 否 — "不得息"在原文中为惊痫发作伴随症状，不可直接等於 bronchial asthma |
| **可直接用于临床？** | 否 — 不可輸出针刺深度/灸量/疗程，不可替代哮喘急性发作的吸入治療 |

### 必须给出的限定

1. **"小兒驚癎，不得息，顱𩕄主之"不可等同为《甲乙经》有儿童哮喘取穴方案** — 原文病证为"惊痫"（癫痫类发作），"不得息"是惊痫伴随症状，非独立哮喘诊断
2. **卷九的咳逆上气诸穴（魄户、气舍、扶突等）为成人小儿通用** — 原文未限定年龄，不可作为"儿童专属方案"
3. **所有取穴方案仅供学术研究参考** — 不可替代现代哮喘指南的阶梯治疗
4. **禁止家庭自行操作** — 儿童针灸必须在执业中医师+儿科专科医生共同评估后方可进行

### 可保留的历史文献线索

1. 颅囟、昆仑、商丘三穴是《甲乙经》中明确用于小儿的与呼吸/喘相关的穴位 — **此为可引用的历史文献事实**
2. 卷九咳逆上气篇的辨证框架完整覆盖呼吸困难的脏腑辨证 — 提供了理解《甲乙经》时代"喘/不得息"治疗思路的系统文本
3. 卷十二"小儿杂病第十一"共 22 条儿科取穴，涉及 18 个穴位 — 是《甲乙经》儿科针灸的基本证据群
