# 00 Project Charter — 项目章程

---

> **版本:** V0.1
> **状态:** Draft
> **适用范围:** 全项目 · 全角色
> **维护者:** 项目负责人

## 1. 使命

为古籍数字人文研究提供可信任的、AI 增强的文献管理与知识发现基础设施。

### 为什么叫皇甫谧

皇甫谧（215–282），魏晋医学家，著《针灸甲乙经》，整理《黄帝内经》。他以"述而不作，信而好古"的态度，系统整理前人医学文献，使之可传承、可检索、可应用。本平台以他为名，致敬这种精神：**将古籍整理为结构化数据，使人文研究可计算、可验证、可复现**。

## 2. 愿景

### 2.1 近期（0-6 个月）

一个可工作的人文文献管理平台，支持：

- 古籍文本的结构化导入与多版本管理
- 人物、地点、事件、概念的实体抽取与关系建模
- 基于 RAG 的文献问答

### 2.2 中期（6-12 个月）

- GraphRAG 知识图谱推理
- 跨文献语义检索
- 学术研究工具链（版本比对、出处溯源、引用网络）

### 2.3 远期（12 个月+）

- 多语言古籍互译与对齐
- 跨机构数据互操作
- 开放人文知识图谱

## 3. 范围

### 3.1 在范围内

- 中文古籍文献的结构化存储、检索、展示
- 文献的多版本管理（底本、校本、注本）
- 实体（人物、地点、事件、概念）的 CRUD 与关系建模
- RAG / GraphRAG 问答
- 学术友好的 Web UI
- 标准化的 REST API

### 3.2 不在范围内（V1）

- 非中文古籍（但架构预留扩展）
- 图像 OCR 识别（接受已识别的文本输入）
- 实时协作编辑
- 移动端 App
- 公众科普内容（纯研究导向）

## 5. 成功定义

### 5.1 V1 成功标准

1. 至少 3 部古籍完整导入并可检索
2. 实体抽取准确率 ≥ 85%（人工抽样评估）
3. RAG 问答可溯源到原文段落
4. 学术用户可在 30 分钟内独立完成一次文献查询任务
5. 全部 API 有文档，全部数据库表有 ER 图

### 5.2 不做

- 不追求用户量 — 先追求学术严谨性
- 不追求炫酷 UI — 先追求信息密度和可读性
- 不追求模型花哨 — 先追求结果可验证
