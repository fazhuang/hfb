# GUIDE-011：首次研究流程

> 版本：v0.2.0 | 日期：2026-08-09 | 适用于：所有研究者用户

---

## 一、概述

本文档描述 HFB 平台当前可运行的**标准五步古籍研究工作流**。系统旨在为古籍科研（如《针灸甲乙经》等医籍）提供“可计算、可验证、可复现”的研究基础设施。

**一句话主链**：创建课题 → 发起新研究（五步工作流） → 检索与证据审查 → 导出报告。

> **持久化说明**：课题列表及 ID 通过 Pinia Store（`stores/research.ts` 中的 `STORAGE_KEY`）在浏览器本地（`localStorage`）进行持久化保存。刷新页面数据不丢失；当前版本暂不支持跨设备自动同步。

---

## 二、前置条件

1. 已注册并登录 HFB 平台
2. 平台服务正常启动（前端 + 后端 API + 数据库均就绪）

---

## 三、规范路由与分步操作

### 第 1 步：创建或选择研究课题

**位置**：`/research`（课题列表页）

**操作**：

1. 点击「+ 新建课题」输入课题名称（如“针灸甲乙经经络论述比较”）。
2. 在课题详情页（`/research/:projectId`）中：
   - 点击「**继续研究**」：进入研究工作区（`/research/:projectId/workspace`），查看历史笔记、已导出的报告与资料库。
   - 点击「**发起新研究**」：直接拉起标准五步研究工作流（`/research/:projectId/workflow`）。

---

### 第 2 步：运行五步研究工作流

**位置**：`/research/:projectId/workflow`

标准五步工作流依次包含以下环节：

1. **第一步：研究问题 (Research Question)**
   - 输入您关心的古籍研究问题（例如：“_《针灸甲乙经》中关于经络的论述在不同版本有何差异？_”）。
   - 点击「下一步：检索范围确认」。

2. **第二步：检索范围确认 (Retrieval Scope Confirmation)**
   - 系统会自动告知本次检索的语料范围（如《针灸甲乙经》等入库古籍文本）。
   - 系统将根据研究问题自动执行向量与全文检索，不需手动逐篇勾选。
   - 点击「开始分析」。

3. **第三步：AI 分析 (AI Analysis)**
   - 系统后台并发调用大模型与 RAG 检索引擎，定位相关 Passages、版本标记与关联条文。

4. **第四步：证据审查 (Evidence Review)**
   - 逐条审查系统检索出具的古籍原文片段（Passage）、引文页码及版本溯源证据。

5. **第五步：研究报告 (Research Report)**
   - 查看系统生成的结构化研究报告。
   - 报告包含完整的证据数、引用列表及导出按钮，支持一键导出为 Markdown 格式科研报告。

---

## 四、历史研究与工作区管理

**位置**：`/research/:projectId/workspace`

在研究工作区中，您可以：

- **资料与版本**：浏览入库古籍原典及版本差异。
- **笔记管理**：针对研究会话记录研讨笔记。
- **报告查看**：复查与导出该课题下历次运行生成的科研报告。

---

## 五、已知限制与声明

1. **非临床建议声明**：系统生成的分析报告仅供古籍文献考证与学术研究使用，不可作为临床诊疗建议。
2. **全文与图谱范围**：检索精度取决于当前已入库古籍的版本数量与向量化索引状态。
