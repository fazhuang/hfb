# 皇甫谧数字人文平台 — 当前系统操作说明

**版本**: 0.2.0
**更新日期**: 2026年7月11日
**适用对象**: 项目负责人、研究团队、非技术用户

---

## 一、这个系统现在能做什么

### 当前可以正常使用的功能

**1. 注册和登录**

打开浏览器访问系统地址（开发环境: `http://127.0.0.1:5173`），点击右上角"登录"，输入账号密码即可进入系统。

管理员账号: 请联系技术团队获取。
研究人员账号: 可以在登录页面点击注册自行创建。

**2. 浏览文献基本信息**

登录后，点击导航栏的"文献"，可以看到当前系统中收录的文献列表。每篇文献显示：书名、朝代、分类、摘要。

**3. 查看历史人物信息**

点击导航栏的"人物"，可以看到历史医学家的生平信息，包括朝代、生卒年、籍贯、代表著作。

**4. 使用个人工作台**

点击"工作台"，可以创建研究笔记。笔记是纯文本格式，适合记录研究思路。

**5. 使用 AI 翻译和总结**

在研究页面中，可以输入一段古文，让系统翻译成现代汉语，或者生成内容总结。

## 三、如何操作系统

### 启动系统

系统需要由技术人员启动。启动后：

- 前端网址: `http://127.0.0.1:5173`
- 管理后台: 登录管理员账号后可见额外菜单

### 登录

1. 打开系统网址
2. 点击右上角"登录"
3. 输入用户名和密码
4. 登录成功后，导航栏会显示所有可用功能

### 浏览文献

1. 登录后点击导航栏"文献"
2. 看到文献列表
3. 点击任一文献，进入详情页
4. 详情页展示：书名、朝代、作者、摘要、分类

### 创建研究笔记

1. 登录后点击"工作台"
2. 点击"新建会话"
3. 输入标题，创建研究会话
4. 在会话中添加笔记

### 使用 AI 翻译

1. 登录后进入研究页面
2. 在输入框中粘贴需要翻译的古文
3. 选择"翻译"功能
4. 系统返回现代汉语翻译

## 五、当前系统的局限

### 数据方面

1. **文献数量少**: 目前系统中只有 3 篇示例文献（《针灸甲乙经》《伤寒杂病论》《本草纲目》），且只有基本信息，没有全文内容。
2. **没有版本信息**: 每部古籍通常有多个版本（如明刻本、清刻本），但系统中尚未录入。
3. **没有原文内容**: 无法在系统中直接阅读古籍原文。

### 功能方面

1. **大部分页面需要登录**: 如果不登录，只能看到首页和关于页面。
2. **搜索功能只搜索人物**: 当前搜索"针灸甲乙经"只能找到作者皇甫谧，找不到文献本身。
3. **AI 问答依赖数据**: AI 只能基于系统中已有的内容回答问题，数据不足时无法提供有用回答。

## 六、常见问题

**问: 我搜索"针灸甲乙经"为什么找不到这本书？**
答: 这是一个已知问题。书的信息在系统中，但搜索功能目前默认不搜索文献类型。请直接点击导航栏"文献"查看。

**问: 为什么很多页面是空的？**
答: 您可能没有登录。请点击右上角"登录"，输入账号密码后再试。

**问: 能看到古籍原文吗？**
答: 目前还不能。原文内容需要先由技术团队导入系统。导入后即可在系统中阅读和检索。

**问: AI 能帮我写论文吗？**
答: 目前 AI 只能做翻译和总结。研究报告生成功能尚在开发中。

**问: 系统上有哪些文献数据？**
答: 目前有 3 篇示例数据：《针灸甲乙经》（西晋·皇甫谧）、《伤寒杂病论》（东汉·张仲景）、《本草纲目》（明·李时珍）。

**问: 如何添加更多文献？**
答: 请联系技术团队。文献可以通过手动录入或自动采集两种方式添加。自动采集支持从开放学术数据库获取研究文献。
