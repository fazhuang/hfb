# Academic Evidence Research Framework

## 学术证据研究框架

> 本框架定义《皇甫谧数字人文与中医经典智能研究平台》关于学术证据（Academic Evidence）的总体研究体系。
>
> 平台提出 Academic Evidence Framework，将传统文献证据、版本证据、校勘证据、历史证据、数字证据及人工智能推理证据统一纳入可计算的证据体系，构建贯穿科研全过程的数字证据基础设施。
>
> 本框架中的模型、原则及流程属于平台研究框架，用于规范证据组织、证据验证、证据推理及证据管理，并在持续研究实践中不断完善。

---

# 第一章 学术证据研究范式

传统学术研究强调：

> "论从史出，证从文来。"

平台进一步提出：

> **Evidence Before Conclusion.**

任何学术观点都应建立在可验证、可追溯、可复核的证据基础之上。

平台认为：

证据不是论文写作的附属材料。

证据本身就是研究对象。

因此建立：

Academic Evidence Object。

实现证据对象化、结构化、网络化和可计算化。

# 第三章 Evidence Object

平台建立：

Evidence Object。

每项证据建立唯一 Evidence ID。

统一包括：

- 证据名称
- 证据类型
- 来源信息
- Version
- Passage
- 时间
- 地点
- 责任主体
- 数字资源
- 学术说明

Evidence Object 成为知识图谱基础节点。

# 第四章 Evidence Classification

平台建立统一证据分类体系。

包括：

Primary Evidence

第一手文献证据。

Secondary Evidence

第二手研究证据。

Version Evidence

版本证据。

Collation Evidence

校勘证据。

Historical Evidence

历史证据。

Archaeological Evidence

考古证据。

Image Evidence

数字影像证据。

AI Analysis Evidence

AI 分析记录。

AI 输出属于辅助证据，不独立构成学术结论。

```text
↓

Evidence

↓

Citation

↓

Version

↓

Passage

↓

Reasoning

↓

Academic Conclusion
```
