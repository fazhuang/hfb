# Academic Citation Network Research Framework

## 学术引文网络研究框架

> 本框架定义《皇甫谧数字人文与中医经典智能研究平台》关于学术引文网络（Academic Citation Network）的总体研究体系。
>
> 平台提出 Citation Network Framework，将传统文献引用、知识图谱、数字人文网络分析及 AI 推理相结合，建立能够表达知识传承、学术影响、理论演进及研究谱系的数字引文体系。
>
> 本框架中的模型、流程与分析方法属于平台研究框架，用于支撑平台的引文组织、学术分析及知识推理。

---

# 第一章 引文网络研究范式

传统引文主要用于说明资料来源。

平台认为：

引文不仅反映引用关系。

更反映知识传播、理论继承、学术影响及研究共同体的发展过程。

平台提出：

> **Citation as Knowledge Connection**

引用不仅连接文献。

更连接：

- 知识
- 学者
- 理论
- 学派
- 历史
- 思想

形成完整学术网络。

# 第三章 Citation Object

平台建立：

Citation Object。

每一条引用均建立唯一 Citation ID。

统一包含：

- 引文来源
- 引文目标
- 引文类型
- Passage
- Version
- 作者
- 时间
- 页码
- DOI（如适用）
- Persistent Identifier

形成统一引用对象。
