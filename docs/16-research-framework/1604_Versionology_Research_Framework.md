# Versionology Research Framework
## 数字版本学研究框架

> 本框架定义《皇甫谧数字人文与中医经典智能研究平台》提出的数字版本学（Digital Versionology）研究框架。
>
> 本框架提出一套面向数字人文时代的版本研究方法，将传统版本学、目录学、校勘学、文献学与人工智能、知识图谱、图计算及可计算文本分析相结合，构建可持续演进的数字版本研究体系。
>
> 本框架中的概念、模型与流程属于平台研究框架，用于组织平台的研究实践，并将在持续的学术研究中不断完善。

---

# 第一章 数字版本学范式

传统版本学主要关注版本鉴别、源流考证、刊刻系统及校勘关系。

平台认为，在数字人文时代，版本研究的对象已经发生变化。

版本不仅是文献载体，更是能够被描述、计算、推理和持续演化的知识对象。

平台提出数字版本学研究范式：

```text
Version

↓

Knowledge Object

↓

Knowledge Network

↓

Evidence Network

↓

Computable Version

↓

Knowledge Discovery

↓

AI Assisted Research
```

数字版本学的目标不是替代传统版本学，而是在其基础上建立更加开放、更加系统、更加智能的研究模式。

---

# 第二章 Version as Knowledge

平台提出：

> Version is Knowledge.

版本不仅记录文本。

同时记录：

- 文献历史
- 学术演化
- 知识传播
- 学术影响
- 文本关系
- 校勘过程
- 引用历史

因此：

每一个版本均应视为一个完整知识对象。

平台所有版本均具有唯一 Version ID。

# 第五章 Version Genome

平台提出：

Version Genome。

Version Genome 用于描述一个版本最稳定、最具辨识度的数字特征。

包括：

Structural Genome

文本结构特征。

Text Genome

正文特征。

Annotation Genome

批注及校记特征。

Publication Genome

刊刻特征。

Material Genome

载体及物理特征。

Knowledge Genome

知识对象组成。

Relationship Genome

与其它版本之间形成的关系网络。

Version Genome 共同决定版本身份。

# 第六章 Version Ecology

平台提出：

Version Ecology。

任何版本均不是孤立存在。

版本之间共同组成持续演化的生态系统。

生态关系包括：

- 继承
- 引用
- 重刊
- 改编
- 汇编
- 校订
- 注释
- 数字化

Version Ecology 用于解释版本之间长期形成的协同演化关系。

# 第七章 Version Evolution Theory

平台提出：

Version Evolution Theory。

版本演化不是线性过程。

而是网络演化。

```text
Original Version

├── Copy A

│

├── Copy B

│

├── Revised Version

│

├── Annotated Version

│

└── Modern Edition
```

平台采用 Directed Graph 建立 Version Evolution Graph。

支持：

- 演化路径分析
- 分支识别
- 汇聚分析
- 源流重建

# 第八章 Version Evidence Theory

平台建立 Version Evidence Theory。

任何版本判断均必须建立证据链。

证据来源包括：

- 原始版本
- 校勘记录
- 馆藏目录
- 出版信息
- 学术论文
- 历史文献
- 图像资料
- 人工审核记录
- AI 辅助分析记录

平台要求：

所有研究结论均能够追溯至证据来源。
